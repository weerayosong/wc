CASE STUDY

เดิมพันหมดหน้าตัก (All-in Risk)

นาย A ซื้อหุ้น 100%

คาดหวังกำไรสูงสุด แต่เมื่อเกิดวิกฤต หุ้นตกลง -40%
พอร์ตของเขา ติดลบ -40% เต็มๆ (ทนไม่ไหว ขายทิ้ง)

นาย B ซื้อหุ้น 50% / พันธบัตร 50%

วิกฤตเดียวกัน หุ้นตก -40% แต่พันธบัตรบวก +5%
พอร์ตของเขา ติดลบแค่ -17.5% (ยังพอนอนหลับสบาย)

การผสมสินทรัพย์ (Diversification) คือ "เสื้อเกราะกันกระสุน" ของนักลงทุน

%
CONCEPT

ผลตอบแทนของพอร์ต (Weighted Return)

พอร์ตจะเติบโตแค่ไหน ขึ้นอยู่กับ "สัดส่วนน้ำหนัก (Weight)" ที่เราแบ่งเงินไปซื้อสินทรัพย์นั้นๆ

$$ R_{port} = (W_{stock} \times R_{stock}) + (W_{bond} \times R_{bond}) $$
R (Return): ผลตอบแทนของสินทรัพย์
W (Weight): สัดส่วนน้ำหนัก (รวมกันต้องได้ 1.0 หรือ 100%)

ตัวอย่าง: หุ้นกำไร 10% (ลงเงิน 60%) + พันธบัตรกำไร 2% (ลงเงิน 40%)
พอร์ตจะได้กำไร = (0.60 * 10) + (0.40 * 2) = 6.8%

สร้างไฟล์ lesson5_intro.py เรามาลองเขียนสูตรถ่วงน้ำหนักด้วย Python กัน

lesson5_intro.py
# 1. กำหนดผลตอบแทน (Return) ของแต่ละสินทรัพย์
r_stock = 10.0 # หุ้นกำไร 10%
r_bond = 2.0 # พันธบัตรกำไร 2%

# 2. กำหนดสัดส่วนน้ำหนัก (Weight) ให้รวมกันได้ 1.0 เสมอ
w_stock = 0.60 # ลงทุนหุ้น 60%
w_bond = 1.0 - w_stock # ส่วนที่เหลือ 40% ให้พันธบัตร

# 3. คำนวณผลตอบแทนพอร์ตโดยรวม (Weighted Sum)
port_return = (w_stock * r_stock) + (w_bond * r_bond)
print(f"ผลตอบแทนพอร์ต: {port_return:.2f}%")

# --- 2. รับค่า Asset Allocation จากผู้ใช้ ---

# คำนวณหาน้ำหนักของพันธบัตรอัตโนมัติ (และแปลงเป็นทศนิยมเพื่อใช้คูณ)
bond_pct = 100 - stock_pct
w_stock = stock_pct / 100
w_bond = bond_pct / 100

st.write(f"สัดส่วนปัจจุบัน: หุ้น **{stock_pct}%** | พันธบัตร **{bond_pct}%**")
