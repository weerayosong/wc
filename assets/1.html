เป้าหมายในฝันของคุณ คืออะไร?

ลองจินตนาการถึงสิ่งที่คุณอยากได้ในอีก 10 ปีข้างหน้า...

รถยนต์คันแรก

ราคาปัจจุบัน: 1,000,000 บาท

ทุนเรียนต่อ ป.โท

ราคาปัจจุบัน: 1,500,000 บาท

คำถาม: ในอีก 10 ปี ของพวกนี้จะยัง "ราคาเท่าเดิม" ไหม?

%
CONCEPT

โจรล่องหนที่ชื่อว่า "เงินเฟ้อ" (Inflation)

เงินเฟ้อ คือภาวะที่ของแพงขึ้น ทำให้เงินในกระเป๋าเรามี "อำนาจซื้อ (Purchasing Power)" ลดลง

สูตรคำนวณราคาสินค้าในอนาคต (Future Value)

$$ FV = PV \times (1 + r)^n $$
FV (Future Value): ราคาสินค้าในอนาคต
PV (Present Value): ราคาปัจจุบัน
r (Rate): อัตราเงินเฟ้อ (ทศนิยม เช่น 0.03)
n (Time): จำนวนปี
&
CONCEPT

Income vs Wealth

Income (รายได้)

คือสิ่งที่คุณหามาได้จากการทำงาน (Active Income) เช่น เงินเดือน หรือค่าจ้าง

"รายได้เยอะ ไม่ได้แปลว่ารวย... ถ้าใช้หมด"

Wealth (ความมั่งคั่ง)

คือเงินและสินทรัพย์ที่ เหลือเก็บ และถูกนำไปลงทุนให้เติบโต (Passive Income)

"ความมั่งคั่ง คือสิ่งที่จะปกป้องเราจากเงินเฟ้อ"

CODE ALONG

สร้างตัวแปรเก็บข้อมูล (Variables)

เปิด VS Code สร้างไฟล์ชื่อ lesson1.py แล้วพิมพ์โค้ดเพื่อแปลสูตรคณิตศาสตร์เป็น Python

lesson1.py
# 1. กำหนดข้อมูลปัจจุบัน (สมมติเป้าหมายคือซื้อรถ)
present_value = 1000000 # ราคาปัจจุบัน 1 ล้านบาท
inflation_rate = 0.03 # อัตราเงินเฟ้อเฉลี่ย 3% ต่อปี
years = 10 # ระยะเวลา 10 ปี

# 2. คำนวณราคาในอนาคต (ยกกำลังใน Python ใช้ **)
future_value = present_value * ((1 + inflation_rate) ** years)

# 3. แสดงผล (ใช้ f-string เพื่อจัดรูปแบบตัวเลขให้มีคอมม่า)
print(f"ราคาเป้าหมายในอีก {years} ปี: {future_value:,.2f} บาท")
Output: ราคาเป้าหมายในอีก 10 ปี: 1,343,916.38 บาท

CODE ALONG

สร้างฟังก์ชัน (Function) ไว้ใช้งานซ้ำ

เพื่อให้เราเรียกใช้งานสูตรได้หลายรอบโดยไม่ต้องพิมพ์ใหม่ ให้ใช้ def

lesson1.py
def calculate_future_cost(pv, rate, n):
    """ฟังก์ชันคำนวณมูลค่าในอนาคต (FV)"""
    fv = pv * ((1 + rate) ** n)
    return fv

# ลองเรียกใช้งานฟังก์ชันกับเป้าหมายที่ต่างกัน
car_cost = calculate_future_cost(1000000, 0.03, 10)
house_cost = calculate_future_cost(5000000, 0.03, 10)

print(f"ค่ารถ: {car_cost:,.2f} | ค่าบ้าน: {house_cost:,.2f}")

The Rule of 72 & Takeaway

กฎเลข 72 (Rule of 72)

วิธีคิดเลขในใจเร็วๆ ว่าเมื่อไหร่ของจะราคาแพงเป็น 2 เท่า
สูตร: $72 \div \text{อัตราเงินเฟ้อ}$ = จำนวนปี
เช่น เงินเฟ้อ 3% → 72 ÷ 3 = 24 ปี ของจะราคาขึ้นเป็น 2 เท่า!

"เวลา (Time) คือสินทรัพย์ที่มีค่าที่สุดในการสร้างความมั่งคั่ง
และเป็นศัตรูตัวร้ายที่สุด หากเราปล่อยให้เงินเฟ้อกัดกิน"
