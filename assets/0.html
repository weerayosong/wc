STEP 1

ติดตั้งเครื่องยนต์หลัก (Python)

Add python.exe to PATH

STEP 2

ติดตั้งโต๊ะทำงาน (VS Code)

ดาวน์โหลดจาก code.visualstudio.com แล้วติดตั้งตามปกติ

1. สร้างโฟลเดอร์ทำงาน

สร้างโฟลเดอร์ชื่อ wealth-code ไว้ที่ Desktop

เปิดโปรแกรม VS Code แล้วลากโฟลเดอร์นั้นเข้ามาวาง (หรือ File > Open Folder...)

2. ติดตั้งส่วนเสริม (Extensions)

คลิกไอคอน Extensions (สี่เหลี่ยมซ้อนกัน) ค้นหาและติดตั้ง 2 ตัวนี้:

  • Python (โดย Microsoft)
  • Black Formatter (ช่วยจัดโค้ดให้อ่านง่าย)

TERMINAL

ลองพิมพ์คำสั่งนี้เพื่อตรวจสอบว่าติดตั้ง Python สำเร็จหรือไม่:

Terminal (bash/cmd)

STEP 3

คำสั่งสร้างและเปิดใช้ venv

1. สร้างพื้นที่จำลอง (พิมพ์ครั้งเดียวตอนเริ่มโปรเจกต์)

python -m venv env

2. เปิดใช้งาน (พิมพ์ทุกครั้งที่เปิดหน้าต่าง Terminal ใหม่)

# สำหรับ Windows
env\Scripts\activate

# สำหรับ Mac / Linux (หรือใช้ Git Bash บน Windows)
source env/bin/activate
ถ้าเปิดสำเร็จ จะมีคำว่า (env) ปรากฏขึ้นที่หน้าบรรทัดคำสั่ง
[]
STEP 4

ติดตั้งเครื่องมือ (Libraries)

เมื่ออยู่ในโหมด (env) แล้ว ให้ติดตั้ง 3 เครื่องมือหลักที่จะใช้ตลอดหลักสูตรนี้

pip install streamlit pandas numpy

Streamlit

เปลี่ยนโค้ดให้เป็น Web Dashboard สุดล้ำอย่างรวดเร็ว

Pandas

เครื่องมือจัดการตารางข้อมูล (เหมือน Excel แต่เขียนด้วยโค้ด)

Numpy

สุดยอดนักคำนวณคณิตศาสตร์และตัวเลขสถิติขั้นสูง
