CONCEPT

กระแสเงินสด (Cashflow)

กระแสเงินสด คือ "เลือด" ที่หล่อเลี้ยงระบบการเงินของคุณ บ่งบอกสภาพคล่องในแต่ละเดือน

$$ Cashflow = Income - Expenses $$

Positive Cashflow (เงินเหลือ)

รายรับ > รายจ่าย (มีเงินไปลงทุน)

Negative Cashflow (ช็อต)

รายจ่าย > รายรับ (ต้องกู้หนี้)

Savings Rate (อัตราการออม)

ควรตั้งเป้าหมายออมเงินให้ได้อย่างน้อย 10% - 20% ของรายได้เสมอ

&
CONCEPT

ความมั่งคั่งสุทธิ (Net Worth)

ตัวชี้วัดที่แท้จริงว่าคุณ "รวย" แค่ไหน ไม่ใช่วัดที่รถหรือของแบรนด์เนม

Assets

ทรัพย์สิน

  • เงินสด / เงินฝาก
  • หุ้น / กองทุน / คริปโต
  • อสังหาริมทรัพย์
-

Liabilities

หนี้สิน

  • หนี้บัตรเครดิต
  • หนี้ผ่อนรถ / ผ่อนบ้าน
  • หนี้กู้ยืมเรียน
=

BUILD PROJECT (Step 3/7)

คำนวณ Cashflow ด้วย Pandas

พิมพ์ต่อด้านล่าง: ใช้พลังของ Pandas ดึงข้อมูลเฉพาะกลุ่มมาบวกรวมกัน (Sum)

dashboard.py (cont.)
# --- 1. คำนวณ Cashflow ---
# กรองเฉพาะแถวที่เป็น Income แล้วรวมผลลัพธ์ในคอลัมน์ Amount
total_income = cashflow_df[cashflow_df["Type"] == "Income"]["Amount"].sum()

# กรองเฉพาะแถวที่เป็น Expense แล้วรวมผลลัพธ์
total_expense = cashflow_df[cashflow_df["Type"] == "Expense"]["Amount"].sum()

# คำนวณเงินเหลือ และ อัตราการออม
cashflow = total_income - total_expense
savings_rate = (cashflow / total_income) * 100

Syntax Explanation: df[ df["Type"] == "Income" ] หมายถึง "คัดกรองตาราง เอาเฉพาะบรรทัดที่คอลัมน์ Type มีค่าเป็นคำว่า Income"

คำนวณ Net Worth

พิมพ์ต่อด้านล่าง: ใช้วิธีเดียวกันในการแยก Assets และ Liabilities ออกจากตาราง

dashboard.py (cont.)
# --- 2. คำนวณ Net Worth ---
total_assets = networth_df[networth_df["Type"] == "Asset"]["Amount"].sum()
total_liabs = networth_df[networth_df["Type"] == "Liability"]["Amount"].sum()

# คำนวณความมั่งคั่งสุทธิ
net_worth = total_assets - total_liabs

Check Point: ถึงตรงนี้ระบบได้คำนวณตัวเลขสำคัญไว้หมดแล้ว ขั้นตอนต่อไปคือการนำตัวเลขไปแปะลงบนหน้าเว็บ!
